# أذكاري 🌿

موقع عربي ثابت لعرض مجموعة أولية من الأذكار، مع اقتراح قسم بحسب ساعة الجهاز، ومصادر مذكورة بجوار الأذكار، ونسخ النص وعدّاد تكرار.

## التشغيل على الكمبيوتر أو الهاتف

1. فك ضغط ملف ZIP إلى مجلد.
2. افتح `index.html` في المتصفح. ستعمل الواجهة والساعة والعدّادات والنسخ غالبًا محليًا.
3. للحصول على تثبيت PWA والعمل دون اتصال بصورة موثوقة، ارفع الملفات إلى استضافة HTTPS (مثل GitHub Pages) ثم افتح الرابط في Chrome على Android واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن ظهر الخيار.
4. خدمة Service Worker لا تعمل عادةً من `file://` مباشرة؛ تعمل على HTTPS أو `localhost`.

## الملفات

- `index.html`: هيكل الصفحة.
- `styles.css`: التصميم المتجاوب RTL.
- `adhkar.js`: بيانات الأذكار والمصادر.
- `app.js`: الساعة والاقتراحات والعدادات والنسخ والتثبيت.
- `manifest.webmanifest`: بيانات PWA.
- `service-worker.js`: تخزين الملفات الأساسية مؤقتًا.
- `icon.svg`: أيقونة الموقع.

## ملاحظات الأمان والدقة

- لا حسابات ولا API ولا قاعدة بيانات ولا تتبع ولا إعلانات.
- الساعة المحلية اقتراح تنظيمي فقط، وليست حسابًا شرعيًا أو مواقيت صلاة.
- المحتوى **مجموعة أولية وليست موسوعة كاملة**. المصادر مدونة داخل الملف بجوار النصوص، لكن ينبغي مراجعة كل نص ورقم حديث وحكمه على يد مختص قبل نشر الموقع على نطاق واسع. بعض الأذكار مذكورة مع تنبيه إلى وجود كلام في الإسناد، لذلك لا ينبغي وصف جميع محتويات المشروع بأنها متفق على صحتها.
- يستخدم الموقع خطوط النظام محليًا ولا يحتاج إلى طلب خطوط أو مكتبات خارجية.
